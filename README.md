# Javascript 2 Course assignment
JSocial is a social media frontend built for the Javascript 2 CA at Noroff. The application use the Noroff API and vanilla JS with ES6 modules.

## Live website

https://remiytter.github.io/js2-ca/

## Features

- Register an account and log in
- View a feed of posts with pagination
- Search through posts by title or content
- View each post
- Create, edit and delete your posts
- View your own profile and other user's profile
- View posts by a specific user
- Follow and unfollow other users
- Log out

## Tech stack

 - HTML
 - CSS
 - Javascript with ES6 modules
 - Noroff API v2
 - GitHub pages

## Getting started

1. Clone the repository:
   git clone https://github.com/remiytter/js2-ca.git

2. Open the project folder in Visual studio code.
3. Check the API configuration in `js/api/config.js`.
4. Start the project with a local web server, such as the Live Server extension in VSC.
5. Open `index.html` through the local server.

Use a local web server instead of opening the HTML files directly, as the application uses JS modules.

## Project structure

- `css/` - Styles
- `js/api/` - API config and request functions
- `js/pages/` - Page logic and event handlers
- `js/ui` - Shared functions for creating interface elements
- Root HTML files - Application pages
